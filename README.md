# Introduction to Object-Oriented Programming in C++

This repository contains code developed during my first contact with Object-Oriented Programming (OOP) in C++.

The main goal was to learn and practice the fundamental concepts of OOP, without focusing on advanced patterns or complex architecture.

## Repository goal

- Understand the logic of Object-Oriented Programming
- Practice creating and using classes in C++
- Understand how objects interact with each other
- Consolidate the conceptual foundation of OOP

This repository represents an early stage of my learning and reflects my level of knowledge at that time.

## Concepts studied

The main concepts covered were:

- Classes and objects
- Encapsulation
- Constructors and destructors
- Methods and attributes
- Organizing code across `.h` and `.cpp` files

## Project structure

The repository is organized simply, containing standalone examples to practice each concept studied.
